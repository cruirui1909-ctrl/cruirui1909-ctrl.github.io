第一次使用与常见问题

先回到光厅，走近扭蛋机，按住空格让旋钮转满 180°。扭蛋掉出时，对应的星座壁纸自动解锁，之后可以重复下载。记录保存在当前浏览器，刷新和重新打开仍保留；清除浏览器数据或更换浏览器不会自动同步。主页光厅不属于扭蛋奖励。

一个 ZIP 同时包含 Windows 和 macOS 启动文件，选择自己的系统使用即可。每包只含一个场景，所有运行资源随包保存；导入后请保留解压目录。壁纸模式隐藏网页按钮，直接进入场景；静置时柔光缓缓巡游，移动鼠标会恢复跟随。

Windows 启动器查找运行中的 Wallpaper Engine 和 Steam 游戏库，找不到时可手动选择已安装的启动程序。macOS 通过本机地址给 Plash 载入场景；如 Plash 只导入未切换，从它的菜单选中新场景。重启后重新双击启动文件；停止服务可用包内 Stop-macOS.command。本包不会自动安装软件、禁用系统保护或添加开机任务。

原网页的滚轮推进、光圈、气泡、水纹和粒子互动均保留；桌面宿主可能拦截滚轮或鼠标事件，可用“浏览器预览”体验完整交互。Plash 对壁纸静音，声音可在浏览器预览中开启。Windows 启动方式已实测，macOS 仍需要在真实 Mac 上复核。
